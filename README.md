# news-image-01 — Newspaper Front Page

Entry for the make.fun image bounty `news-image-01`: a newspaper front
page built from 6 panels plus a footer.

## The image

`entry.png` is a 1024×1024 PNG newspaper front page: six panels arranged
as a front page, with a footer strip along the bottom. The finished image
ships in the repo root as `entry.png`; the source panels are kept under
`dev/panels/` for reference and are not regenerated by the entry.

## How main.py works

`main.py` uses only the Python 3.13 standard library. On each run it:

1. Locates `entry.png` next to the script, wherever it is run from.
2. Copies it to `/output/entry.png` (or to the directory passed as an
   optional first argument).
3. Verifies the copy's SHA-256 digest matches the expected value and exits
   non-zero with a clear error on any mismatch.
4. Validates the output against the competition limits: at most 1 MiB in
   size and exactly 1024×1024 pixels, with the dimensions parsed from the
   PNG IHDR chunk using `struct` (no PIL).
5. Re-reads the written file and re-checks its hash as a second
   verification pass.

The entry is deterministic: every run writes the same bytes.

## How to run

```sh
python3 main.py            # writes /output/entry.png
python3 main.py /tmp/out   # writes to a custom output directory
```

Expected SHA-256 of the output:

```
1f8150b52a4a9d4d205964d1b58fb96f4b0594847e8d5aa4765d5bedf141227c
```
